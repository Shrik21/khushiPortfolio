# Meethi Talks by Khushi

A premium, editorial, photo-led personal portfolio website for **Khushi**
([@khushi_kathayat07](https://www.instagram.com/khushi_kathayat07)) — an Instagram
influencer and digital creator based in Pithoragarh, Uttarakhand, India.

The site is built to help brand managers quickly understand Khushi's audience,
content quality, campaign results, services, and collaboration process — with
"Work With Me" / "Send Enquiry" as the primary conversion goal.

## Visual concept

**"Hillside editorial meets daily love vibes."** Quiet luxury, warm Indian
cultural styling, natural hill-town landscapes, candid creator energy, and
polished magazine composition. An offset vertical filmstrip of Khushi's
portraits is the site's recurring visual signature, first seen in the hero and
echoed subtly in the portfolio section.

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React 19, file-based routing)
- [Tailwind CSS v4](https://tailwindcss.com/) with a custom design-token layer
  (ivory, warm beige, ink, antique gold, soft rose, deep berry)
- [shadcn/ui](https://ui.shadcn.com/) components on Radix UI primitives
- [Lucide](https://lucide.dev/) icons
- Vite + Nitro for build/SSR

## Getting started

```bash
# install dependencies
npm install   # or: bun install

# start the dev server
npm run dev

# type-check
npx tsc --noEmit

# lint
npm run lint

# production build
npm run build
```

The dev server runs on Vite's default port unless configured otherwise.

## Project structure

```
src/
  routes/
    index.tsx        # the entire one-page site (header → footer)
    __root.tsx        # app shell / root layout
  components/ui/       # shadcn/ui primitives
  assets/photos/       # Khushi's real photography, used throughout the site
  styles.css           # design tokens, keyframes, and shared utilities
```

`src/routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin —
don't edit it by hand.

## Page sections

Header/nav · Hero · About · Instagram statistics · Audience insights ·
Featured collaborations · Portfolio (filterable, with lightbox) · Services ·
Why work with Khushi · Testimonials (carousel) · Awards & recognition · FAQ
(accordion) · Contact form · Footer.

All brand names, campaign metrics, and testimonials in the Collaborations and
Testimonials sections are **editable placeholder content** and should be
verified before the site goes live.

## Content notes

- All photography is Khushi's own, sourced from `src/assets/photos` — no stock
  imagery is used anywhere on the site.
- Copy, pricing, and stats are easily editable from the data constants at the
  top of `src/routes/index.tsx`.
